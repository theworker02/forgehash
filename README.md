# forgehash

Forge and reshape hash text streams with deterministic transforms.

**Site:** https://theworker02.github.io/forgehash/

## Install / run

```bash
git clone https://github.com/theworker02/forgehash.git
cd forgehash
node src/cli.js
node --test
```
